# The First Programmer's Book

📘 _The First Programmer's Book_ is an educational non-fiction project, initially written in Ukrainian and later translated into English.
It is aimed at complete beginners who want to learn programming step-by-step using Python.

## What’s inside the book?

- Programming basics explained in plain language
- Python fundamentals: variables, data types, loops, functions and error handling
- Small projects and games (e.g., Guess the Number, Magic 8 Ball, Hangman)
- Pop art illustrations and a touch of humor 🙂

## What’s inside the repository?

- Code samples from the book
- Chapter directories cover `04`–`30`, preserving the book’s numbering; chapters `01`–`03` are not included in this code-sample repository.
- Each chapter has separate `en/` (English) and `ua/` (Ukrainian) directories, each with its own README and examples.
- Chapter READMEs describe the available examples and sections; sample-file headings identify the corresponding book sections. Section numbers may skip sections without code samples.
- Chapter `05` contains terminal and console examples directly in its READMEs; chapter `30` contains further-learning resources. The full book manuscript is not included.
