# Розділ 28. Функції

Цей розділ містить приклади з книги **"Перша книга програміста"**.  
Ми детально розглядаємо **функції у Python** — як їх створювати, передавати параметри, повертати значення, документувати, уникати типових помилок та робити код зрозумілішим і структурованим.

## Зміст прикладів

- **28.1 Створення і виклик функції** → базовий синтаксис: ключове слово `def`, виклик функції, приклади без параметрів.
- **28.2 Створення і виклик функції з параметрами** → створення та виклик функції з одним параметром, різниця між параметром і аргументом.
- **28.3 Назва функції** → правила найменування згідно з [PEP 8](https://peps.python.org/pep-0008/#function-and-variable-names).
- **28.4 Функції з кількома параметрами** → приклад функції з кількома параметрами.
- **28.5 Кількість аргументів** → відповідність кількості аргументів обов'язковим параметрам функції, помилка `TypeError` у разі відсутності аргументу.
- **28.6 Позиційні аргументи** → передавання аргументів відповідно до порядку параметрів у визначенні функції.
- **28.7 Іменовані аргументи** → передавання аргументів за назвами параметрів, комбінування позиційних та іменованих аргументів, покращення читабельності викликів функцій.
- **28.8 Передавання змінної як аргументу функції** → передавання значень через змінні, локальні імена та області видимості, переприсвоєння параметрів без зміни зовнішніх змінних.
- **28.9 Значення параметра за замовчуванням** → необов'язкові аргументи, використання значень за замовчуванням і правила розташування параметрів у визначенні функції.
- **28.10 Повернення результату функції** → повернення значень за допомогою `return`, збереження результату у змінній, кілька `return` у функції, ранній вихід та повернення `None`.
- **28.11 Змінні типи даних як аргументи функції** → передавання списків як аргументів, зміна об'єктів усередині функції, різниця між зміною об'єкта та переприсвоєнням параметра.
  ⚠️ Розглянуто типову помилку зі змінними об'єктами як значеннями параметрів за замовчуванням (`friends=[]`) та правильний варіант із `None`.
- **28.12 Використання pass** → створення «заглушок» і порожніх функцій, відмінність між `pass` та `return`.
- **28.13 Виклик функцій усередині інших функцій** → виклик однієї функції з іншої, використання `main()` для організації логіки програми.
- **28.14 Документація функцій** → створення рядків документації (`docstring`), використання потрійних лапок `"""` та отримання документації через `__doc__`.
- **28.18 Для допитливих: `*args`, `**kwargs`** → довільна кількість позиційних та іменованих аргументів, збирання їх у кортежі та словники, використання `**` для розпакування словників під час виклику функцій.
- **28.19 Для допитливих: лише позиційні параметри (`/`)** → використання `/` у визначенні функції для обмеження передавання аргументів лише за позицією.
- **28.20 Для допитливих: лише іменовані параметри (`*`)** → використання `*` у визначенні функції для обов'язкового передавання аргументів за іменами параметрів.
- **28.21 Для допитливих: комбінування позиційних (`/`) та іменованих (`*`) параметрів** → одночасне використання `/` та `*`, розмежування параметрів за способом передавання аргументів.
- **28.22 Для допитливих: вкладені функції** → створення функцій усередині інших функцій, використання змінних зовнішньої функції у вкладеній.
- **28.23 Для допитливих: Google style для документації функцій** → розширене документування функцій у стилі Google, секції `Args:` і `Returns:`, опис параметрів, їхніх типів та повернених значень.

## Як запускати приклади

У цьому розділі наведені лише короткі приклади, без готових програм.  
Щоб їх перевірити:  

1. Скопіюйте потрібний блок коду.  
2. Вставте його у файл (наприклад, `example.py`) або в онлайн-інтерпретатор.  
3. Запустіть файл у терміналі:  
    ```bash
    python3 example.py
    ```
    або запустіть програму в онлайн-інтерпретаторі.

⚠️ Деякі приклади спеціально містять помилки (`TypeError`, `SyntaxError`, `NameError`), щоб продемонструвати роботу механізму функцій у Python.
